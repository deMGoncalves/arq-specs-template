# Architect - Troubleshooting

**ID**: SKL-002

## Problema: Design Muito Complexo

**Sintomas**: design.md >2000 lines, múltiplos bounded contexts

**Solução**: Dividir sistema em modules, criar design.md por module

## Problema: ADRs Insuficientes

**Sintomas**: Decisões críticas sem ADR

**Solução**: Criar ADR para cada trade-off significativo (mínimo 3-5 ADRs para HIGH)
